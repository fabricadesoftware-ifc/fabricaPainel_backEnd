# Security Policy

Fabrica Painel is developed and owned by **Fábrica de Software** at the
Instituto Federal Catarinense (IFC), Campus Araquari, Brazil.

## Security maintainer

- **Jonatas Silva Peraza** ([@jonatasperaza](https://github.com/jonatasperaza)) — creator, maintainer and security contact

## Supported versions

Only the latest version on the `main` branch (the one deployed in
Fábrica de Software's infrastructure) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through one of these channels:

- GitHub private vulnerability reporting: the **"Report a vulnerability"**
  button under this repository's **Security** tab
- Email: jonatassilvaperaza@gmail.com

Please include:

- a description of the issue and its potential impact;
- steps to reproduce or a proof of concept;
- the affected version or commit, if known.

## What to expect

- We will acknowledge your report as soon as possible.
- We will keep you informed while we investigate and fix the issue.
- Once a fix is deployed, we can credit you in the release notes if you wish.

## Scope

This policy covers the Fabrica Painel codebase and its deployment within
Fábrica de Software's infrastructure. Applications hosted on Fabrica Painel
belong to their respective authors and are out of scope.
